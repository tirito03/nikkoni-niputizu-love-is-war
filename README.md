# NIKKONI NIPUTIZU — Love Is War

Гумористична анкета знайомств українською мовою. React 19, TypeScript, Vite 6, Tailwind CSS 4, Motion та React Router.

## Перегляд

Потрібен Node.js 24 LTS (версію також задано для Vercel). Відкрийте термінал у папці проєкту:

```sh
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite, зазвичай http://localhost:5173.

Для відтворюваного встановлення використовуйте `npm ci`: точні версії записано в `package-lock.json`. Попередній `pnpm-lock.yaml` збережено, але Vercel явно використовує npm.

## Збірка

```sh
npm run build
npm run preview
```

Збірка перевіряє TypeScript та створює папку `dist`. Preview зазвичай доступний на http://localhost:4173. Якщо порт зайнятий, використайте адресу з термінала.

## Підготовка до Vercel і GitHub

Автоматичної публікації не виконано. Дизайн, тексти, фотографії та механіки залишаються без змін.

У корені є `vercel.json`: Vite, встановлення `npm ci`, збірка `npm run build`, результат `dist`. Правило `/(.*) → /index.html` дозволяє React Router обробляти пряме відкриття й оновлення `/game`; наявні статичні файли Vercel обслуговує як файли. Зображення копіюються Vite з `public/images` у `dist/images` та використовують адреси `/images/…`, без префікса `/public`. Конфігурація відповідає [офіційній інструкції Vercel для Vite SPA](https://vercel.com/docs/frameworks/frontend/vite#using-vite-to-make-spas).

Перед публікацією можна повторити:

```sh
npm ci
npm run build
npm test
npm run test:prayer
npm run check:images
npm run preview
```

Для перевірки зображень через готову збірку в іншому терміналі виконайте `node scripts/verify-images.mjs --url=http://localhost:4173` (або вкажіть фактичну адресу Preview).

## Симулятор побачень

Сюжет містить кімнату Дениса, аніме-іспит, геополітичну кризу HOI4, самокат за 800 €, випробування Святого Равлика та справжнє побачення. Незнання аніме не блокує романтичні кінцівки: є варіанти зі щирим інтересом. Приховані умови враховують гумор, повагу, інтерес і попередні вибори.

Кінцівки: Good («Побачення відбулося»), Bad («Ще один бій»), HOI4 («Спільне завоювання Європи»), Anime («Вайфу понад усе»), Secret («800 € за годину»), True («Nikkoni Niputizu») і Snail Secret («Благословення Равлика»). Кожна має окрему ілюстрацію та діалог.

Прогрес, відкриті кінцівки й прочитані репліки зберігаються лише в `localStorage` поточного браузера під ключем `nikkoni-love-is-war-v1`. Точний стан відновлюється після оновлення сторінки, зокрема посеред реакції. Кнопка перезапуску скидає поточне проходження, зберігаючи колекцію кінцівок та прочитаний текст. Пропуск доступний лише для вже прочитаних реплік і ніколи не обирає відповідь автоматично. Історію реплік можна розгорнути праворуч / нижче діалогу.

При заблокованому сховищі гра продовжує працювати в пам’яті та показує попередження. Пошкоджене або несумісне збереження безпечно відхиляється. Збереження попередньої версії підтримуються через міграцію, описану нижче.

Структура для продовження розробки:

- `src/game/story.ts` — епізоди, репліки, відповіді, реакції, зміни показників та кінцівки.
- `src/game/engine.ts` — переходи, умови кінцівок, відновлення збереження, пропуск і перезапуск.
- `src/game/DatingGame.tsx` — інтерфейс гри; `src/game/game.css` — адаптивне оформлення.
- `src/ProfileExtras.tsx`, `src/RpgStats.tsx` — додаткові розділи анкети та секретні реакції.
- `src/App.tsx` — наявна анкета й маршрути; `src/main.tsx` лише запускає React. Це зберігає стабільну роботу гарячого оновлення Vite без повторного створення React-кореня.

## Культ Святого Равлика та РПУ

Молитва має незалежний шанс 4% на жартівливий дроп TURMS. Використовується наданий файл `public/images/turms.png` (562 × 284) без редагування чи заміни. Рідкісна подія показує декоративне списання уявних равликомонет, підтвердження, золоте відкриття й картку нагороди. Кнопки дозволяють прийняти дар або зробити нову випадкову молитву; Escape закриває подію, таймери очищаються. Це не оплата й не видача техніки у War Thunder. Попередні жарти збережені.

Звук відкриття нагороди враховує наявний перемикач; для `prefers-reduced-motion` прибрано частинки та сяйво, переходи скорочено. Перевірка `npm run test:prayer` підтверджує межу 4%, 400 рідкісних результатів на рівномірній сітці з 10000 значень та відсутність послідовних повторів звичайних реплік. Код: `src/snail/prayer.ts`, `src/snail/TurmsDrop.tsx`, `src/snail/SnailCult.tsx`.

На головній сторінці додано секцію `#snail`: золотий SVG-вівтар, випадкові молитви, коротке сяйво й 12 частинок на натискання. Повторний результат не випадає одразу поспіль. Усі бонуси, донат, пробиття й знижки — суто мемні; зв’язку з War Thunder, оплат чи запитів до Gaijin немає. Додано жарти про страх Дениса торкнутися трави.

РПУ всюди позначено як пародію на уявну систему, а не як доведену механіку. Індикатор на головній і в грі змінює фразу раз на 18 секунд, лише коли він у полі зору та вкладка активна; автофрази можна вимкнути. Автофрази не озвучуються й не переривають екранний читач. Кнопка перевірки або третя відповідь у новій сцені показують коротке червоне попередження, яке можна закрити.

Звук початково вимкнено. Його вмикає лише явне натискання перемикача; вибір зберігається окремо під ключем `nikkoni-snail-sound-v1`. Сигнал синтезується Web Audio (0,56 секунди), без завантаження аудіофайлів і циклів. Вимкнення зупиняє звук; одночасні сигнали обмежено. Непідтримуване чи заблоковане аудіо не ламає сайт. З налаштуванням `prefers-reduced-motion` немає частинок, сяйва й glitch-руху, а інформація залишається доступною статично.

Шоста сцена загальної арки — побачення; п’ята — «Випробування Святого Равлика». Три відповіді мають різні наслідки для вигаданої симпатії, а «РПУ не існує» запускає пародійне попередження. Сьома кінцівка потребує благословення, достатніх показників і подальшого запрошення до манґа-кафе. Попередні Good, Bad, HOI4, Anime, 800 € і True залишилися досяжними. Finanzamt згадується в самокатному мемі та новій кінцівці.

### Сумісність збережень

Новий формат має версію 2 та той самий ключ сховища. Приймаються старі збереження версії 1: їхня поточна арка продовжується старим маршрутом із незмінними показниками й відкритими кінцівками. Нове випробування з’являється після початку нової арки. Позначка старого маршруту зберігається і після наступних перезавантажень. Перевірка містить 21 справжній зразок попередньої версії — репліки, вибори, реакції й усі шість старих кінцівок.

Код секції, SVG-вівтаря, звукових ефектів та РПУ розміщено у `src/snail/`; сюжет і умови продовжують зберігатися в `src/game/story.ts` та `src/game/engine.ts`.

### Зображення аніме й обкладинки ігор

Додано `rei-ayanami.png`, `violet-evergarden.png`, `ai-hoshino.png`, `hoi4-cover.png` та `war-thunder-cover.png` у `public/images`. Усі взято з офіційних промоматеріалів; `sex-with-stalin.png` використовується повторно, без заміни й дублювання. Джерела та правовласники зазначені в `public/images/card-artwork-sources.md`; офіційне походження не є відкритою ліцензією. Вручну додавати файли не потрібно.

Картки персонажів мають однакову висоту в одному ряду, вертикальні вікна з `object-fit: cover`, індивідуальне позиціювання портретів, темний градієнт і плавне збільшення при наведенні. Обкладинки у геймерській кар’єрі та секретній бібліотеці показано повністю з `object-fit: contain`. Нові зображення завантажуються відкладено, мають розміри для стабільної верстки та наявний компонент запасного повідомлення при помилці. Для п’яти нових PNG додано WebP-варіанти (28–63 КБ) через `srcSet`; PNG залишені резервними адресами. Рух враховує `prefers-reduced-motion`. Перевірка зображень тепер охоплює 22 основні файли та п’ять оптимізованих варіантів.

Офіційну обкладинку Steam без відвертих сцен збережено локально як `public/images/sex-with-stalin.png` (460 × 215). Джерело записано в сусідньому файлі `sex-with-stalin.source.txt`. Під час користування пасхалкою немає звернень до Steam. Модальне вікно підтримує Escape, повернення фокусу, клавіатурну навігацію, мобільний екран і зменшення руху.

У бічній панелі `/game` є необов’язкова розмова про історію XX століття. Кожна відповідь дає малий бонус один раз за арку, не пересуває основний діалог і зберігається разом із проходженням. Другий варіант показує червоне повідомлення на одну секунду. Перевірка рушія охоплює цю розмову, захист від повторного бонусу та відновлення збереження. Код: `src/steam/`.
