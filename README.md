# NIKKONI NIPUTIZU — Love Is War

Гумористична анкета знайомств українською мовою. React 19, TypeScript, Vite 6, Tailwind CSS 4, Motion та React Router.

## Перегляд

Потрібен Node.js 24 LTS (версію також задано для Vercel). Відкрийте термінал у папці проєкту:

```sh
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite, зазвичай http://localhost:5173.

Для відтворюваного встановлення використовуйте `npm ci`: точні версії записано в `package-lock.json`. Попередній `pnpm-lock.yaml` збережено, але Vercel явно використовує npm.

## Збірка

```sh
npm run build
npm run preview
```

Збірка перевіряє TypeScript та створює папку `dist`. Preview зазвичай доступний на http://localhost:4173. Якщо порт зайнятий, використайте адресу з термінала.

## Підготовка до Vercel і GitHub

Автоматичної публікації не виконано. Дизайн, тексти, фотографії та механіки залишаються без змін.

У корені є `vercel.json`: Vite, встановлення `npm ci`, збірка `npm run build`, результат `dist`. Правило `/(.*) → /index.html` дозволяє React Router обробляти пряме відкриття й оновлення `/game`; наявні статичні файли Vercel обслуговує як файли. Зображення копіюються Vite з `public/images` у `dist/images` та використовують адреси `/images/…`, без префікса `/public`. Конфігурація відповідає [офіційній інструкції Vercel для Vite SPA](https://vercel.com/docs/frameworks/frontend/vite#using-vite-to-make-spas).

Перед публікацією можна повторити:

```sh
npm ci
npm run build
npm test
npm run test:prayer
npm run check:images
npm run preview
```

Для перевірки зображень через готову збірку в іншому терміналі виконайте `node scripts/verify-images.mjs --url=http://localhost:4173` (або вкажіть фактичну адресу Preview).

## Симулятор побачень

Сюжет містить кімнату Дениса, аніме-іспит, геополітичну кризу HOI4, самокат за 800 €, випробування Святого Равлика та справжнє побачення. Незнання аніме не блокує романтичні кінцівки: є варіанти зі щирим інтересом. Приховані умови враховують гумор, повагу, інтерес і попередні вибори.

Кінцівки: Good («Побачення відбулося»), Bad («Ще один бій»), HOI4 («Спільне завоювання Європи»), Anime («Вайфу понад усе»), Secret («800 € за годину»), True («Nikkoni Niputizu») і Snail Secret («Благословення Равлика»). Кожна має окрему ілюстрацію та діалог.

Прогрес, відкриті кінцівки й прочитані репліки зберігаються лише в `localStorage` поточного браузера під ключем `nikkoni-love-is-war-v1`. Точний стан відновлюється після оновлення сторінки, зокрема посеред реакції. Кнопка перезапуску скидає поточне проходження, зберігаючи колекцію кінцівок та прочитаний текст. Пропуск доступний лише для вже прочитаних реплік і ніколи не обирає відповідь автоматично. Історію реплік можна розгорнути праворуч / нижче діалогу.

При заблокованому сховищі гра продовжує працювати в пам’яті та показує попередження. Пошкоджене або несумісне збереження безпечно відхиляється. Збереження попередньої версії підтримуються через міграцію, описану нижче.

Структура для продовження розробки:

- `src/game/story.ts` — епізоди, репліки, відповіді, реакції, зміни показників та кінцівки.
- `src/game/engine.ts` — переходи, умови кінцівок, відновлення збереження, пропуск і перезапуск.
- `src/game/DatingGame.tsx` — інтерфейс гри; `src/game/game.css` — адаптивне оформлення.
- `src/ProfileExtras.tsx`, `src/RpgStats.tsx` — додаткові розділи анкети та секретні реакції.
- `src/App.tsx` — наявна анкета й маршрути; `src/main.tsx` лише запускає React. Це зберігає стабільну роботу гарячого оновлення Vite без повторного створення React-кореня.

## Культ Святого Равлика та РПУ

Молитва має незалежний шанс 4% на жартівливий дроп TURMS. Використовується наданий файл `public/images/turms.png` (562 × 284) без редагування чи заміни. Рідкісна подія показує декоративне списання уявних равликомонет, підтвердження, золоте відкриття й картку нагороди. Кнопки дозволяють прийняти дар або зробити нову випадкову молитву; Escape закриває подію, таймери очищаються. Це не оплата й не видача техніки у War Thunder. Попередні жарти збережені.

Звук відкриття нагороди враховує наявний перемикач; для `prefers-reduced-motion` прибрано частинки та сяйво, переходи скорочено. Перевірка `npm run test:prayer` підтверджує межу 4%, 400 рідкісних результатів на рівномірній сітці з 10000 значень та відсутність послідовних повторів звичайних реплік. Код: `src/snail/prayer.ts`, `src/snail/TurmsDrop.tsx`, `src/snail/SnailCult.tsx`.

На головній сторінці додано секцію `#snail`: золотий SVG-вівтар, випадкові молитви, коротке сяйво й 12 частинок на натискання. Повторний результат не випадає одразу поспіль. Усі бонуси, донат, пробиття й знижки — суто мемні; зв’язку з War Thunder, оплат чи запитів до Gaijin немає. Додано жарти про страх Дениса торкнутися трави.

РПУ всюди позначено як пародію на уявну систему, а не як доведену механіку. Індикатор на головній і в грі змінює фразу раз на 18 секунд, лише коли він у полі зору та вкладка активна; автофрази можна вимкнути. Автофрази не озвучуються й не переривають екранний читач. Кнопка перевірки або третя відповідь у новій сцені показують коротке червоне попередження, яке можна закрити.

Звук початково вимкнено. Його вмикає лише явне натискання перемикача; вибір зберігається окремо під ключем `nikkoni-snail-sound-v1`. Ефекти відтворюються Web Audio з локальних MP3 у `public/sounds`, без синтезованих замін та циклів. Це дозволені CC0-аналоги, а не оригінальна озвучка War Thunder. Вимкнення зупиняє звук; одночасні сигнали обмежено. Непідтримуване чи заблоковане аудіо не ламає сайт. З налаштуванням `prefers-reduced-motion` немає частинок, сяйва й glitch-руху, а інформація залишається доступною статично.

Шоста сцена загальної арки — побачення; п’ята — «Випробування Святого Равлика». Три відповіді мають різні наслідки для вигаданої симпатії, а «РПУ не існує» запускає пародійне попередження. Сьома кінцівка потребує благословення, достатніх показників і подальшого запрошення до манґа-кафе. Попередні Good, Bad, HOI4, Anime, 800 € і True залишилися досяжними. Finanzamt згадується в самокатному мемі та новій кінцівці.

### Сумісність збережень

Новий формат має версію 2 та той самий ключ сховища. Приймаються старі збереження версії 1: їхня поточна арка продовжується старим маршрутом із незмінними показниками й відкритими кінцівками. Нове випробування з’являється після початку нової арки. Позначка старого маршруту зберігається і після наступних перезавантажень. Перевірка містить 21 справжній зразок попередньої версії — репліки, вибори, реакції й усі шість старих кінцівок.

Код секції, SVG-вівтаря, звукових ефектів та РПУ розміщено у `src/snail/`; сюжет і умови продовжують зберігатися в `src/game/story.ts` та `src/game/engine.ts`.

## Інтерактивний гумор, характеристики й сумісність

Для мемів використовується один `MemePopupProvider` у `src/humor/MemePopup.tsx`: теми War Thunder, HOI4, аніме, Святого Равлика та RPG. Є повторна випадкова цитата без негайного повтору, коментар, закриття кнопкою, Escape або фоном, утримання та повернення фокусу. Тло стає неінтерактивним, тому popup не складаються один поверх одного; старі повноекранні пасхалки зберігають власні інтерфейси. Переходи скорочуються з `prefers-reduced-motion`.

У `src/humor/catalog.ts` є 35 цитат War Thunder (15 заданих і 20 нових), незалежні набори щонайменше шести реплік для кожної з восьми основних характеристик, меми пасивної здібності, особистості та вісім результатів сумісності. Значення первинних і додаткових RPG-шкал збережено. У геймерській кар’єрі додані кнопки бойового мему й секретного протоколу HOI4.

Молитва має 44 звичайні результати з категоріями благословення, прокляття, абсурд і легендарні повідомлення; усі початкові молитви залишилися в наборі. Результат відкривається в тематичному popup із кнопкою нової молитви. `src/snail/prayer.ts`, шанс TURMS 4%, зображення танка та `TurmsDrop.tsx` не змінювалися. Перехід із нагороди до popup очікує завершення попередньої анімації. Фраза про «благословення TURMS» у звичайному наборі — окремий жарт, а не видача рідкісної картки. Звуки враховують попередній перемикач.

У «Ідеальній половинці» використано незмінене фото `photo_2026-11-06_20-42-36.jpg`, десять мемних критеріїв, конкуренцію за увагу героя, жартівливий індикатор 3% і кнопку сумісності. Останній приклад у наданому завданні обривався на «Святий Равлик сх…»; завершено як «Святий Равлик схвалив вашу коаліцію».

Перевірки: `npm run test:humor`, `npm run test:prayer`, `npm test`, `npm run check:images`, `npm run build`. Новий тест перевіряє достатність наборів, усі обов’язкові War Thunder-фрази, коментарі, унікальність і неповторюваність цитат та збереження початкових молитов. Старі тести підтверджують 4% рідкісних результатів і 1309 сюжетних проходжень із сімома кінцівками. У браузері перевірено всі вісім характеристик, повернення фокусу, молитви, реальне випадіння й прийняття мемного TURMS, Steam-досягнення, Finanzamt, фотогалерею та `/game`; popup вміщуються на екранах 390 × 844 і 320 × 568.

## Секретна бібліотека Steam

У «Геймерській кар’єрі Дениса» розгорніть «TOP SECRET / ЗАСЕКРЕЧЕНІ ФАЙЛИ». Бібліотека — вигаданий мем, не підтверджений список реального акаунта. Картка Sex with Stalin запускає системний діалог і відкриває секретну RPG-шкалу. Три натискання дають досягнення «ІСТОРИЧНИЙ РОМАНТИК»; прогрес зберігається локально під ключем `nikkoni-history-library-v1`.

### Зображення аніме й обкладинки ігор

Додано `rei-ayanami.png`, `violet-evergarden.png`, `ai-hoshino.png`, `hoi4-cover.png` та `war-thunder-cover.png` у `public/images`. Усі взято з офіційних промоматеріалів; `sex-with-stalin.png` використовується повторно, без заміни й дублювання. Джерела та правовласники зазначені в `public/images/card-artwork-sources.md`; офіційне походження не є відкритою ліцензією. Вручну додавати файли не потрібно.

Картки персонажів мають однакову висоту в одному ряду, вертикальні вікна з `object-fit: cover`, індивідуальне позиціювання портретів, темний градієнт і плавне збільшення при наведенні. Обкладинки у геймерській кар’єрі та секретній бібліотеці показано повністю з `object-fit: contain`. Нові зображення завантажуються відкладено, мають розміри для стабільної верстки та наявний компонент запасного повідомлення при помилці. Для п’яти нових PNG додано WebP-варіанти (28–63 КБ) через `srcSet`; PNG залишені резервними адресами. Рух враховує `prefers-reduced-motion`. Перевірка зображень тепер охоплює 22 основні файли та п’ять оптимізованих варіантів.

Офіційну обкладинку Steam без відвертих сцен збережено локально як `public/images/sex-with-stalin.png` (460 × 215). Джерело записано в сусідньому файлі `sex-with-stalin.source.txt`. Під час користування пасхалкою немає звернень до Steam. Модальне вікно підтримує Escape, повернення фокусу, клавіатурну навігацію, мобільний екран і зменшення руху.

У бічній панелі `/game` є необов’язкова розмова про історію XX століття. Кожна відповідь дає малий бонус один раз за арку, не пересуває основний діалог і зберігається разом із проходженням. Другий варіант показує червоне повідомлення на одну секунду. Перевірка рушія охоплює цю розмову, захист від повторного бонусу та відновлення збереження. Код: `src/steam/`.


## Оновлення молитви та локального аудіо

Єдина база `src/data/quotes.ts` містить 56 мемів War Thunder і 146 звичайних результатів молитви; старі репліки збережено. RPG, молитва й універсальні вікна використовують спільні записи з категорією, звуком і візуальним ефектом. Додано благословення, прокляття, абсурдні та легендарні результати.

На кожне натискання незалежно перевіряються 4% для TURMS і 3% для секретної появи Равлика. При збігу перемагає TURMS: фактична частота видимої події Равлика — 2,88%. Перша фраза змінюється на попередження РПУ за 1,5 секунди; це вигаданий мем, а не механіка War Thunder. Розкриття TURMS, фотографії, маршрути та сюжетні кінцівки збережено. У вікні TURMS клавіатура також дістається регулятора гучності й посилання на джерела.

У `public/sounds` встановлено 10 справжніх MP3 із дозволених бібліотек CC0. Вони **не є оригінальними звуками War Thunder** і не містять російськомовних голосових реплік. Металеві влучання замінюють голосові події; запис феєрверка використано як аналог пострілу та вибуху. Повний список авторів, джерел, обробки й ліцензій — у `public/sounds/README.md`, машинний реєстр із SHA-256 — `public/sounds/sources.json`. Сторінка `/sounds/credits.html` дозволяє прослухати всі файли. Після публікації аудіо завантажується тільки з власного сайту.

Звук вимкнений для нового відвідувача; перемикач у шапці та налаштування гучності зберігаються в браузері. Навіть збережене ввімкнення не запускає звук після перезавантаження без дії користувача. На телефонах AudioContext розблоковується натисканням кнопки до завантаження файлу. Одночасно звучить максимум один ефект; вимкнення, закриття вікна, перехід між сторінками й прихована вкладка зупиняють його. Відкладені завантаження скасовуються логічно й не озвучують застарілу подію. Якщо звук недоступний, візуальна подія продовжується. Короткі ефекти враховують `prefers-reduced-motion`.

Додаткові перевірки:

```sh
npm run test:humor
npm run test:prayer
npm run test:audio
npm run check:sounds
node scripts/verify-sounds.mjs --url=http://localhost:5184
```

Перевірка аудіо охоплює відсутність автозапуску, вимкнення й нульову гучність, кеш, відкидання застарілого завантаження та заборону одночасних звуків. Перевірка файлів перевіряє формат MP3, хеші, розмір, тривалість, запас піків і локальну видачу сервером.


### ПАЗик і перевірка UwUpad

Додано один спільний мем «ПОПАДАНИЕ В ПАЗИК» із п’ятьма випадковими коментарями до RPG та абсурдних молитв. Результати пошуку, конкретні сторінки UwUpad і статуси прав записані в `public/sounds/uwupad-review.md` та `.json`. Нових аудіофайлів із цього сайту не встановлено через непідтверджені права на повторне розміщення. `hit-pazik.mp3` не створено, заміни іншими звуками немає; відповідний запис у `unavailableSounds` запобігає запиту до відсутнього файла. Інструкція додавання дозволеного файла — у звіті. Шанси рідкісних подій залишилися незмінними.


### Поточне оновлення файлів користувача (2026-11-07)

Користувач замінив 7 записів і додав ПАЗик. Підключено всі 11 поточних MP3; `hit-pazik.mp3.mp3` перейменовано на `hit-pazik.mp3`, блокування його відтворення прибрано. Попередній звіт UwUpad описує історичний стан до ручного додавання файлів. Актуальні файли, тривалості, хеші та походження — у `public/sounds/sources.json` і `public/sounds/README.md`. Користувацькі файли не позначаються як CC0 або підтверджена оригінальна озвучка.

`src/audio/assetVersions.ts` містить версії за SHA-256 і коефіцієнти запасу гучності. Нові URL усувають старі файли з кешу; надмірні піки послаблюються тільки під час відтворення, байти наданих записів не змінені. РПУ, молитва, RPG і popup використовують той самий спільний плеєр; шанс 3%, шанс TURMS 4%, гучність і початково вимкнений звук збережені. Оновлення залишено локально.


### Ребаланс активної молитви

В активному пулі 32 результати: 16 пріоритетних мемів War Thunder, 10 авторських жартів Равлика та 6 абсурдних повідомлень. `src/snail/prayerPools.ts` посилається на записи спільної бази без копіювання чи видалення. Повні 146 записів залишилися в каталозі для інших секцій; попередні згадки про доступність усіх 146 саме в молитві описують стару версію.

Після незмінних незалежних перевірок TURMS (4%) та секретної реакції (3%, пріоритет TURMS) спочатку обирається група з вагами 65% / 20% / 15%, потім цитата всередині групи. Попередня цитата виключається лише з обраної групи — це запобігає негайному повтору без зміни ваг. Ці відсотки стосуються звичайних результатів. Аудіофайли, прив’язки звуків і решта секцій не змінені.

`test:prayer` перевіряє межі ваг, точний розподіл 6500/2000/1500 на рівномірній сітці з 10000 значень для кожного можливого попереднього активного результату, досяжність усіх 32 цитат, відсутність повторів та незмінність секретних шансів.


### Контекст звуку в універсальних popup

`MemePopup` має явний контекст: `prayer` і `war-thunder-stat` дозволяють звук; `other-stat`, `other` та відсутній контекст залишають popup тихим незалежно від звукових метаданих цитати. RPG визначає контекст за стабільним ID `war-thunder`, а не назвою характеристики. Це правило також застосовується до повторної цитати та ввімкнення звуку всередині popup. Відкриття тихого popup і закриття будь-якого popup зупиняють поточний ефект та відкладене відтворення. Глобальний перемикач, гучність, звуки окремих пасхалок і баланс молитви не змінені.


### МіГ-29 і випадкове голосове повідомлення

На головній додано четверту картку МіГ-29. Три наявні картки та їхній вигляд збережені; нова картка має широку фотографію, щоб не обрізати крила. Реальний літак сфотографував Md Shaifuzzaman Ayon; локальні JPEG/WebP — похідні зменшеного розміру під CC BY-SA 4.0. Атрибуція в картці й `public/images/mig-29.source.md`.

`ScrollVoiceMessage` обирає поріг між 25% і 80% тільки після жесту прокручування (колесо, touch або клавіші). Показується максимум раз за сесію вкладки, позначка зберігається в sessionStorage. Немає показу в `/game`, над формою заявки або поверх модального вікна. Закриття доступне кнопкою чи Escape; перехід у гру закриває повідомлення. Короткий toast після жартівливого блокування зникає за секунду. Підтримується reduced motion.

Плеєр має Play/Pause, часову шкалу, тривалість, перемотування та хвильову анімацію тільки під час відтворення. Сам не запускає звук, враховує наявні mute і гучність. `AudioFocus` не дозволяє голосу звучати одночасно з мемним ефектом; закриття, приховування вкладки й маршрут зупиняють голос.

Запис UwUpad 108970 перевірено: сторінка «хозяин я играла с клубочком», автор завантаження kwava, прев’ю 26,831 с. Дозволу на повторне розміщення не знайдено, тому `clubochkom.mp3` НЕ завантажено. На основному сайті немає звукової заміни: Play показує стан відсутнього запису. Інструкція ручного додавання — `public/sounds/clubochkom.README.md`. Після додавання дозволеного MP3/OGG/WAV `predev`/`prebuild` автоматично виявляє файл та створює версійований локальний шлях.

Команда `npm run test:easter-eggs` перевіряє межі порога, захист від повторів і перезавантаження, виключення гри/форми/модалок, fallback сховища, взаємне зупинення аудіо та розпізнавання вручну доданого файла в ізольованій тестовій папці.


### Підключено надане голосове аудіо

Після попереднього звіту користувач додав `clubochkom.mp3.mp3`. Файл перейменовано на `clubochkom.mp3`, перевірено декодування та підключено локально (26,83 с, 341985 байт). Тому попередні згадки про відсутність цього файла описують минулий стан. `src/easter-eggs/voiceAsset.ts` тепер містить версійовану адресу встановленого запису; джерело й хеш записані у `public/sounds/clubochkom.source.json`. Запис не підмінено іншим аудіо.
