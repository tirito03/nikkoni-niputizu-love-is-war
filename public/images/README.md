# Фотографії та арти

Оригінальні файли не змінюються. `denis-hero.png.jpg` — головний портрет. Усі 11 файлів `photo…jpg` — галерея. `game-room.png.png`, `game-scooter.png.png`, `gamge-good-ending.pn.png` — початкова сцена, самокат за 800 € та щаслива кінцівка відповідно.

Подвійні розширення враховано у шляхах; перейменування не потрібне. Повний перелік із розмірами знаходиться у `src/data/images.json`. При додаванні нових фото додайте їх туди та запустіть `node scripts/verify-images.mjs`.

Файл «Зображення ChatGPT…» збережено без змін і не використовується, бо його призначення не вказане.
