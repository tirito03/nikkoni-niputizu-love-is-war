# Голосове повідомлення: clubochkom

Поточний файл `clubochkom.mp3` надано користувачем і підключено до голосового повідомлення. Виправлено подвійне розширення; звукові байти не змінено. Тривалість 26,830729 с, розмір 341985 байт. Походження й ліцензію незалежно не підтверджено; метадані й SHA-256 записані в `clubochkom.source.json`. Потрібна сторінка з попереднього запиту: https://ru.uwupad.me/sound/108970 .

Відтворення локальне, тільки кнопкою Play, з Pause, перемотуванням, прогресом, загальною гучністю та вимкненням звуку. Закриття повідомлення зупиняє запис. Немає звернень до UwUpad під час відтворення.

Для майбутньої заміни залишити один файл `clubochkom.mp3`, `clubochkom.ogg` або `clubochkom.wav` та оновити метадані джерела. `npm run dev` / `npm run build` автоматично запускає скрипт визначення формату й версії за хешем. Для вже запущеного dev-сервера виконати `node scripts/sync-voice-asset.mjs` та оновити сторінку.
